# Fire Lamp

Прошивка Wi-Fi лампы на **NodeMCU v3 / ESP8266** с матрицей **WS2812B 16×16** и
сенсорной кнопкой на D2. Управление с телефона или компьютера через браузер,
без облака и отдельного сервера.

## Возможности

- Семь режимов: **Огонь → Огонь 2012 → Цвет → Сияние → Плазма → Гипноз → Океан**.
- Плавные переходы при включении, выключении, смене режима, яркости и цвета — 700 мс.
- Отдельная яркость, скорость **25–300%** и тонирование каждого анимированного эффекта.
- Цветовой круг с насыщенностью для постоянного света и тонирования эффектов.
- Автоматический список «Мои лампы» и управление каждой лампой или всеми сразу.
- Постоянная синхронизация: изменение света на одной лампе передаётся остальным,
  в том числе от сенсора и при закрытом браузере.
- Настройка домашнего Wi-Fi из списка сетей; начальная точка доступа без пароля.
- Сохранение настроек и сброс удержанием сенсора 10 секунд.

## Коротко о подключении

| Сигнал | Куда подключить |
| --- | --- |
| Данные матрицы `DIN` | **D4 / GPIO2** через 74AHCT125 и резистор 330–470 Ом |
| Выход `OUT` сенсора TTP223 | **D2 / GPIO4** |
| Питание сенсора | **3V3** NodeMCU, общий GND |
| Питание матрицы | **5 В напрямую от блока питания**, отдельной веткой |
| Питание NodeMCU в собранной лампе | Вход **VIN** от 5 В, если это допускает конкретная плата |

Матрица не питается через USB или дорожки NodeMCU. Подробная схема, питание,
преобразователь уровня и монтаж описаны в [инструкции по сборке](docs/HARDWARE.md).

## Быстрый старт

1. Соберите лампу по [схеме](docs/HARDWARE.md) и [загрузите прошивку](docs/FLASHING.md).
2. Подключитесь к Wi-Fi **`firelamp-XXXXXX` без пароля**.
3. Откройте **http://192.168.4.1**.
4. Выберите домашнюю сеть **2,4 ГГц**, введите её пароль и сохраните.
5. После перезапуска откройте IP лампы из списка клиентов роутера или Serial Monitor.
6. Повторите для остальных ламп: в одной сети они появятся в «Мои лампы» автоматически.

## Управление сенсором

| Жест | Действие |
| --- | --- |
| Одно касание | Включить / выключить |
| Двойное касание | Следующий режим |
| Тройное касание | Постоянный цвет, следующий оттенок |
| Удержание от 0,6 секунды | Изменение яркости; следующее удержание меняет направление |
| Непрерывное удержание 10 секунд | Сброс настроек и возврат к открытой сети лампы |

## Сборка из исходников

Нужен [PlatformIO](https://platformio.org/). В терминале из папки проекта:

```sh
pio run -e nodemcuv2
pio run -e nodemcuv2 -t upload
pio device monitor -b 9600
```

Веб-интерфейс автоматически встраивается во flash; отдельная загрузка файловой
системы не требуется. Готовая проверенная сборка:
[fire-lamp-nodemcu-16x16.bin](firmware/fire-lamp-nodemcu-16x16.bin).

Размеры, разводка матрицы и лимит тока находятся в [include/config.h](include/config.h).
По умолчанию: GPIO2, змейка 16×16, первый пиксель снизу слева, лимит матрицы 2000 мА.

## Совместимость и ограничения

- Основная конфигурация — NodeMCU v3 ESP8266 с CH340G и RGB-матрица WS2812B 5 В,
  порядок цветов GRB. Есть профиль сборки `d1_mini`.
- Нужны общий домашний Wi-Fi и доступ ламп друг к другу. Изолированная гостевая сеть
  может блокировать обнаружение и синхронизацию.
- Синхронизируются команды и параметры света; фазы анимаций могут различаться.
- API работает по HTTP без авторизации, точка настройки открытая. Используйте
  доверенную локальную сеть; доступ через интернет и OTA не реализованы.
- Пароль Wi-Fi сохраняется во flash устройства, в исходниках и готовом `.bin` его нет.
- Проверка работоспособности кода не заменяет проверку вашей разводки и блока питания.

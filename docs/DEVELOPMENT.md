# Код, API и проверки

## Структура проекта

| Путь | Содержимое |
| --- | --- |
| `src/main.cpp` | ESP8266, Wi-Fi, HTTP API, хранение, синхронизация и рендер кадров |
| `include/config.h` | Размеры, пин матрицы, разводка и расчётный лимит тока |
| `include/modes.h` | Постоянные имена/индексы эффектов, ключи настроек, порядок сенсора |
| `include/fire.h` | Исходный «Огонь 2020» и преобразование координат матрицы |
| `include/fire_variants.h` | Fire2012 |
| `include/effects.h` | Сияние, плазма, гипноз и океан |
| `include/animation.h` | Часы скорости и кривая плавного перехода |
| `include/peer_state_cache.h` | Ограниченный кэш состояния соседей для неблокирующего GET |
| `include/touch_button.h` | Подавление дребезга и распознавание жестов |
| `include/sync_version.h` | Разрешение конфликтов и версий синхронизации |
| `include/lamp_registry.h` | Кэш найденных устройств и защита от дублей |
| `web/index.html` | Встроенный интерфейс без внешних CDN |
| `scripts/embed_web.py` | Генерация заголовка с веб-страницей перед сборкой |
| `tests/` | Проверки C++, интерфейса и опциональные аппаратные сценарии |
| `firmware/` | Готовый `.bin` базовой конфигурации |
| `licenses/`, `THIRD_PARTY.md` | Условия и атрибуция стороннего кода |

Индексы хранения не совпадают с порядком отображения: Fire2012 хранится под
индексом 6, хотя показывается вторым. Это сохраняет цвета старых эффектов при
обновлении. Не переставляйте enum без миграции сохранённых настроек.

## HTTP API

Все пути относятся к лампе, на чей IP отправлен запрос. HTTP, порт 80,
ответы JSON, без авторизации. Используйте только внутри доверенной сети.

| Метод и путь | Действие |
| --- | --- |
| `GET /api/state` | Состояние света, имя, ID, IP, подключение и `syncEnabled` |
| `POST /api/state` | Частичное изменение световых параметров и имени |
| `GET /api/discover` | Текущая лампа и найденные соседи, без блокирующего сканирования |
| `GET /api/remote?host=IP` | Последний UDP-снимок состояния другой лампы; без сетевого ожидания |
| `POST /api/remote?host=IP` | Команда другой лампе через текущую |
| `GET /api/wifi` | Сохранённый SSID, подключение, IP и hostname; без пароля |
| `GET /api/wifi/scan` | Асинхронный поиск SSID: 202 пока идёт, 200 когда готово |
| `POST /api/wifi` | Сохранение `{ "ssid": "Home", "password": "…" }` и перезапуск |
| `POST /api/sync` | `{ "enabled": true }` или `false`: общая синхронизация |
| `GET /api/button` | Пин, полярность и текущее состояние входа |
| `POST /api/button` | Настройка сенсора, например `{ "pin": 4, "activeLow": false }` |
| `GET /api/diagnostics` | Кадры, часы анимации, uptime, память, причина перезапуска, RSSI, максимальная задержка цикла |

`POST /api/state` принимает:

| Поле | Значение |
| --- | --- |
| `power` | bool |
| `mode` | `fire`, `fire2012`, `color`, `aurora`, `plasma`, `hiphotic`, `pacifica` |
| `name` | 1–48 байт UTF-8 |
| `hue`, `saturation` | Постоянный цвет: 0–359 и 0–255 |
| `effectHue`, `effectSaturation` | Тонирование текущего/переданного режима: 0–359 и 0–255 |
| `effectCustomColor` | bool, включить собственный цвет эффекта |
| `<mode>Brightness` | Целое 0–255, например `fire2012Brightness` |
| `<mode>Speed` | Целое 25–300, например `plasmaSpeed` |

Поле `syncEnabled` возвращается в состоянии, но меняется отдельным `/api/sync`.
Неверное или неизвестное поле светового запроса отклоняет весь запрос до применения.
Тонирование применяется к режиму из того же запроса; если `mode` нет — к текущему.

Пример:

```sh
curl -X POST http://IP-ЛАМПЫ/api/state \
  -H 'Content-Type: application/json' \
  -d '{"mode":"fire2012","power":true,"fire2012Brightness":100,"fire2012Speed":75}'
```

Сенсор по умолчанию: GPIO4/D2 и HIGH. Для отключения без сенсора:

```sh
curl -X POST http://IP-ЛАМПЫ/api/button \
  -H 'Content-Type: application/json' \
  -d '{"pin":-1,"activeLow":false}'
```

Разрешённые входы: -1 (отключено), 5/D1, 4/D2, 14/D5, 12/D6, 13/D7.
Для инверсного модуля используйте `activeLow: true`. В веб-интерфейсе настройки
сенсора специально не показываются. Параметры сохраняются без перезапуска.

Удалённый HTTP-прокси принимает только IPv4 другой лампы в той же подсети,
фиксированный порт 80 и путь `/api/state`. Произвольные URL не пересылаются.

## Сеть и хранение

- Настройки устройства — `/config.json` в LittleFS; запись через временный файл.
- Световые изменения сохраняются через 2 секунды после последней команды.
- Домашний SSID и пароль не зашиты в код; пароль никогда не возвращается в API.
- Список интерфейса кэшируется в localStorage, а не переносит настройки Wi-Fi.
- UDP 4210: объявление присутствия и полный снимок состояния раз в 5 секунд
  (также после изменений), плюс версионированная синхронизация.
- `GET /api/remote` читает только кэш снимков: до 12 соседей, 1023 байт на снимок,
  срок годности 15 секунд. При отсутствии снимка возвращает 503. Обновите обе лампы: старые
  версии не отправляют снимки. Автоматический опрос больше не ждёт TCP-ответа соседа.
- `POST /api/remote` по-прежнему выполняет HTTP-команду с тайм-аутом 800 мс;
  при недоступности адресата возможна короткая пауза именно при отправке команды.
- mDNS `_firelamp._tcp`: дополнительное обнаружение без блокировки анимации.
- Повторы синхронизации — три пакета; периодический обмен — раз в 4 секунды.
- Конфликты команд решаются версиями и ID отправителя; старые пакеты не применяются.
- Скорость передаётся необязательным расширением для совместимости с ранними версиями.
- Удержание сенсора 10 секунд удаляет конфигурацию самой лампы, не форматируя всю flash.

## Сборка

[Подробная инструкция](FLASHING.md). Закреплённые зависимости находятся в
`platformio.ini`: ESP8266 platform 4.2.1, FastLED 3.6.0, ArduinoJson 6.21.5.

```sh
pio run -e nodemcuv2
```

Простой тест документации и комментариев не требует перепрошивки ламп.

## Проверки без аппаратуры

С установленным C++11-компилятором из корня проекта:

```sh
c++ -std=c++11 -I include tests/modes.cpp -o /tmp/fire-lamp-modes-test
/tmp/fire-lamp-modes-test
c++ -std=c++11 -I include tests/touch_button.cpp -o /tmp/fire-lamp-touch-test
/tmp/fire-lamp-touch-test
c++ -std=c++11 -I include tests/animation.cpp -o /tmp/fire-lamp-animation-test
/tmp/fire-lamp-animation-test
c++ -std=c++11 -I include tests/sync_version.cpp -o /tmp/fire-lamp-sync-test
/tmp/fire-lamp-sync-test
c++ -std=c++11 -I include tests/lamp_registry.cpp -o /tmp/fire-lamp-registry-test
/tmp/fire-lamp-registry-test
```

Проверяются порядок семи режимов, жесты/10-секундный сброс, кривая перехода,
скорость, конфликты команд, повторные пакеты, автопоиск и смена IP.

Браузерные проверки выполняются через Playwright на HTTP-имитаторе ламп:

```sh
npm ci
npm test
```

Текущий тест настроен на установленный Google Chrome в стандартном пути macOS
(`/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`). Для другой ОС
измените `executablePath` в `tests/ui.cjs`. Node.js/npm нужны для этих проверок,
а не для сборки или работы самой прошивки.

## Опциональные проверки на настоящей лампе

```sh
python3 tests/sync_hardware.py http://IP-ЛАМПЫ
python3 tests/animation_hardware.py http://IP-ЛАМПЫ
```

Эти сценарии временно меняют свет и общую синхронизацию, затем восстанавливают
настройки. Запускайте их отдельно, когда такое изменение уместно. Компьютер должен
быть в той же подсети; тест синхронизации использует UDP 4210.
Проверка RGB-кадров не измеряет физический свет, температуру и ток матрицы.

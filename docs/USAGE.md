# Настройка и управление

## Подключение к домашней сети

1. Включите лампу. Если она ещё не настроена или не смогла подключиться к роутеру,
   появится Wi-Fi **`firelamp-XXXXXX` без пароля**. Суффикс уникален для платы.
2. Подключитесь к этой сети с телефона или компьютера. Если телефон предупреждает
   «Нет интернета», оставайтесь в сети лампы.
3. Откройте **http://192.168.4.1** обычным браузером.
4. В блоке **«Домашний Wi-Fi»** выберите сеть из автоматически найденного списка.
   ESP8266 подключается к **2,4 ГГц**. Для скрытой сети введите SSID вручную.
5. Введите пароль роутера и нажмите **«Сохранить и подключить»**.
6. Лампа перезапустится. Переключите телефон обратно на домашний Wi-Fi.
7. Найдите адрес лампы в списке клиентов роутера или в Serial Monitor на 9600 бод,
   затем откройте **`http://IP-лампы`**.

При ошибке подключения примерно через 12 секунд лампа снова откроет собственную
сеть. Можно исправить пароль или выполнить сброс. После изменения настроек сети
адрес может поменяться; не используйте IP из чужой инструкции как фиксированный.
Адрес `http://firelamp-XXXXXX.local` может работать, если устройство и сеть
поддерживают mDNS, но IP роутера остаётся основным способом доступа.

## Эффекты и цвет

В интерфейсе доступны:

| Режим | Вид |
| --- | --- |
| Огонь | «Огонь 2020» из GyverLamp2, шум Перлина и искры |
| Огонь 2012 | Моделирование подъёма и охлаждения тепла по столбцам матрицы |
| Цвет | Постоянный выбранный цвет |
| Сияние | Зелёные, бирюзовые и фиолетовые ленты |
| Плазма | Цветные волны |
| Гипноз | Изгибающийся радужный узор Hiphotic |
| Океан | Сине-зелёные волны Pacifica с бликами |

- Кнопка питания включает или выключает свет, не отключая Wi-Fi.
- **Яркость** хранится отдельно для каждого режима, от 0 до 255.
- **Скорость эффекта** — от 25% до 300%. 100% соответствует обычному темпу.
  Для постоянного цвета ползунок скрыт.
- В режиме «Цвет» выберите оттенок на круге и насыщенность. Центр круга — белый.
- В анимированных режимах включите **«Свой цвет эффекта»**, чтобы открыть цветовой
  круг. Форма и движение эффекта сохраняются, палитра заменяется выбранным тоном.
  Выключите переключатель, чтобы вернуть исходную палитру.
- В **«Настройки этой лампы»** можно присвоить имя, например «Спальня».

Включение, выключение и изменение световых настроек сглаживаются за 700 мс.
Новая команда во время перехода продолжает изменение от текущего кадра.
Цвет, насыщенность, яркость и скорость сохраняются отдельно по режимам;
обычный цвет независим от тонирования анимаций.

## Сенсорная кнопка

Сенсор подключён к **D2 / GPIO4**, по умолчанию активный HIGH, без фиксации.
Настроек кнопки в веб-интерфейсе нет.

| Жест | Результат |
| --- | --- |
| 1 касание | Включить / выключить свет |
| 2 касания подряд | Следующий эффект и включение света |
| 3 касания подряд | Включить режим «Цвет» и сдвинуть оттенок на 30° |
| Удержание от 600 мс | Менять яркость текущего режима |
| Следующее удержание | Менять яркость в другую сторону |
| Непрерывное удержание 10 секунд | Сбросить настройки и перезапуститься в режиме настройки Wi-Fi |

Одиночное касание распознаётся с паузой 350 мс: лампа ждёт возможного второго.
При удержании яркость меняется в диапазоне 5–255; в интерфейсе доступен и ноль.
Отпускание после удержания не считается отдельным касанием.

Порядок переключения:
**Огонь → Огонь 2012 → Цвет → Сияние → Плазма → Гипноз → Океан → Огонь**.
Удержанный при включении сенсор не создаёт случайные клики; для обычных жестов
его сначала нужно отпустить. Длительное удержание при включении позволяет сброс.

## Несколько ламп и автопоиск

Прошейте все платы актуальной версией и подключите каждую к одному домашнему Wi-Fi.
В интерфейсе любой лампы раздел **«Мои лампы»** заполнится автоматически:
текущая лампа показывается первой, другие добавляются в течение нескольких секунд.
Ввод IP и ручной запуск поиска обычно не нужны.

Лампы объявляют себя каждые 5 секунд по UDP; дополнительно используется фоновый
mDNS. Интерфейс обновляет обнаружение примерно раз в 6 секунд, состояния — раз
в 3 секунды. ID платы постоянный: смена имени или IP не должна создавать дубль.
Список до 12 соседей кэшируется в браузере, поэтому ранее найденная выключенная
лампа может оставаться с пометкой «Нет связи».

- Выберите лампу в списке для индивидуального управления.
- **«Управлять всеми»** — разовая отправка следующих настроек всем лампам из списка.
- В свёрнутом блоке **«Если лампа не найдена»** оставлен резервный ввод IP.

Автопоиск не включает синхронизацию и не меняет световые параметры.
Он не объединяет устройства из разных роутеров, подсетей или изолированных гостевых сетей.

## Постоянная синхронизация

Чекбокс **«Синхронизация всех ламп»** включает общий режим устройств в одной подсети.
Включить или выключить его можно в интерфейсе любой лампы; значение передаётся
остальным и сохраняется во flash. Для этого браузер не обязан оставаться открытым.

При включении группа принимает текущее состояние той лампы, где поставлен чекбокс.
Затем от любой лампы, включая управление сенсором, передаются:

- включение и выключение;
- выбранный эффект;
- яркость и скорость текущего режима;
- постоянный цвет и тонирование эффекта.

Имена, пароли Wi-Fi и аппаратный сброс остаются индивидуальными. Снятие чекбокса
возвращает независимое управление. Группа включает все совместимые лампы в этой
подсети, а не только устройства, добавленные в текущем браузере.

Синхронизация означает одинаковые команды и параметры, а не одинаковый кадр:
фазы анимации и случайные искры могут различаться. После краткой потери связи
лампа получает актуальное состояние из периодического обмена. Все функции
доступны при актуальной прошивке на каждой плате.

## Сохранение и сброс

Световые настройки записываются примерно через **2 секунды** после последнего
изменения. Не отключайте питание сразу, если нужно сохранить новое значение.
Настройка домашнего Wi-Fi записывается перед перезапуском.

Для полного сброса **держите сенсор 10 секунд непрерывно**, затем отпустите его.
Удаляются имя, домашняя сеть, световые параметры, настройка синхронизации и сенсора.
Лампа перезапускается и создаёт открытую сеть `firelamp-XXXXXX` с адресом
**http://192.168.4.1**. Настройки остальных ламп и кэш браузера не удаляются.
При повторном подключении к домашней сети включённая на других устройствах
синхронизация может снова включиться на этой лампе.

Обычное обновление прошивки не требует сброса. Ранее удалённые эффекты
«Костёр» и «Свечи» в актуальной версии отсутствуют; если такой режим был сохранён
в старой прошивке, после обновления выбирается исходный огонь.

## Частые вопросы

| Проблема | Что проверить |
| --- | --- |
| Нет сети `firelamp-…` | Лампа уже подключилась к роутеру; найдите её IP. Для новой настройки удерживайте сенсор 10 секунд |
| Не открывается 192.168.4.1 | Телефон подключён именно к сети лампы и не переключился обратно из-за отсутствия интернета |
| Нет домашнего SSID | Нужен диапазон 2,4 ГГц; обновите список или введите SSID вручную |
| Лампы не видят друг друга | Обе реально включены, подключены к одному Wi-Fi, обновлены; отключена изоляция клиентов |
| Синхронизация не работает | Включён чекбокс; роутер пропускает UDP broadcast 4210; одинаковая актуальная прошивка |
| Огонь повёрнут | Настройки ориентации матрицы в `include/config.h`, затем пересборка |
| Цвета перепутаны | Порядок RGB/GRB в `FastLED.addLeds` |
| Сенсор не реагирует | D2, питание 3,3 В, общая земля, моментальный режим и активный HIGH |
| На высокой яркости перезапуски или мусор | Питание, общая земля, падение напряжения, DATA, преобразователь уровня |
| Яркость ограничивается | Лимит FastLED по умолчанию 2000 мА; повышать только после проверки питания и проводки |
| В браузере осталась старая версия интерфейса | Обновите страницу с перезагрузкой кэша |

HTTP/API не имеют авторизации, точка настройки открытая. Проект рассчитан на
доверенную локальную сеть; не пробрасывайте порт 80 и UDP 4210 в интернет.
